# Supplementary Text S2. EltonTraits distance variants

EltonTraits distances were calculated from the species-level data of Wilman et al. (2014). The core variant used ln-transformed body mass (BodyMass-Value), foraging stratum (ForStrat-Value, treated as nominal), and three activity indicators (Activity-Nocturnal, Activity-Crepuscular, and Activity-Diurnal), entered as numeric 0/1 variables. The diet-extended variant additionally included all ten diet-percentage fields: Diet-Inv, Diet-Vend, Diet-Vect, Diet-Vfish, Diet-Vunk, Diet-Scav, Diet-Fruit, Diet-Nect, Diet-Seed, and Diet-PlantO. Gower dissimilarities were calculated using cluster::daisy with equal weights for each input variable.

Name matching used Canis lupus for Canis lupus familiaris and Equus caballus for Equus ferus przewalskii; the other seven study species matched their names directly. These substitutions applied to the EltonTraits alternatives. The matched names and complete trait inputs are provided in h3_elton_traits.csv in the accompanying repository. Each alternative distance replaced the core functional-biomechanical distance in the primary mixed-effects model, retaining classifier identity and the random-effects structure. Distances were standardized to mean zero and unit standard deviation within the data used for each analysis (Table S13).
